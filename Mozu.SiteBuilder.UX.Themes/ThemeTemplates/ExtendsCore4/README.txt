 Mozu Theme Scaffolding                                                    v1.0
================================================================================

The base theme directory should contain, at minimum, a `theme.json` file stating
the name of the theme, the devices it serves, the author information, and what,
if any, theme it extends. It may also contain:

*   a `thumb.jpg` file to serve as a thumbnail when merchants are selecting your 
    theme from a list

*   a `theme-ui.json` file that specifies in ExtJS config syntax (a JSON dialect)
    what control panel options should be available for merchants to modify theme
    settings
